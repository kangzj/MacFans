# MacFans Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship MacFans v1: a native macOS app that shows sensor temperatures and fan RPM, and controls fans in Auto, Constant, and rule-based Custom modes through a root helper with a safety watchdog.

**Architecture:** A SwiftPM package (`SMCKit` for IOKit/SMC access, `MacFansCore` for pure models, sensor catalog, rule engine, and persistence) is consumed by two Xcode targets generated by XcodeGen: the SwiftUI app (reads SMC directly, runs the engine, owns the UI) and a root launchd daemon registered through `SMAppService` that performs the only SMC writes over XPC and reverts fans to Auto if heartbeats stop.

**Tech Stack:** Swift 6.3 (strict concurrency), SwiftUI, Swift Charts, IOKit, `SMAppService` + `NSXPCConnection`, XcodeGen, Swift Testing.

**Spec:** `docs/superpowers/specs/2026-09-10-macfans-design.md`

## Global Constraints

- Minimum deployment target: macOS 15. Apple Silicon first; Intel gets raw keys only.
- Bundle identifiers: app `com.jasperkang.macfans`, helper `com.jasperkang.macfans.helper` (also the Mach service name and launchd label).
- All SMC writes happen in the helper. The app never calls `SMCConnection.write`.
- Every fan RPM sent to hardware is clamped to `[F<n>Mn, F<n>Mx]` read by the helper itself.
- Helper watchdog: no heartbeat for 10 s while any fan is forced → all fans back to Auto.
- Auto is restored on app quit, system sleep, profile switch, and helper shutdown.
- Sensor readings outside `-40...150 °C` or exactly `0` are discarded for that sample.
- Commit messages: plain, no AI attribution (per `~/.claude/rules/git-github.md`). Author is Jasper Kang.
- Swift code: no comments unless non-obvious. `public` API on package targets only where the app or helper needs it.
- Tests: Swift Testing (`import Testing`) in `Packages/MacFansKit/Tests`. Run with `swift test --package-path Packages/MacFansKit` (works with Command Line Tools; set `DEVELOPER_DIR=/Library/Developer/CommandLineTools` if the Xcode license is not yet accepted).

`SMCKey.swift`:

```swift
public struct SMCKey: Hashable, Comparable, Sendable, CustomStringConvertible {
    public let code: UInt32

    public init(code: UInt32) { self.code = code }

    public init(_ string: String) {
        precondition(string.utf8.count == 4, "SMC keys are exactly four ASCII characters")
        code = string.utf8.reduce(0) { ($0 << 8) | UInt32($1) }
    }

    public var string: String {
        String(decoding: [24, 16, 8, 0].map { UInt8(truncatingIfNeeded: code >> $0) }, as: UTF8.self)
    }

    public func hasPrefix(_ prefix: String) -> Bool { string.hasPrefix(prefix) }
    public var description: String { string }
    public static func < (lhs: SMCKey, rhs: SMCKey) -> Bool { lhs.string < rhs.string }
}
```

`SMCDataType.swift`:

```swift
public enum SMCDataType: Equatable, Sendable {
    case flt, sp78, fpe2, ui8, ui16, ui32, si8, si16
    case unknown(String)

    public init(tag: String) {
        switch tag {
        case "flt ": self = .flt
        case "sp78": self = .sp78
        case "fpe2": self = .fpe2
        case "ui8 ": self = .ui8
        case "ui16": self = .ui16
        case "ui32": self = .ui32
        case "si8 ": self = .si8
        case "si16": self = .si16
        default: self = .unknown(tag)
        }
    }

    public var tag: String {
        switch self {
        case .flt: "flt "
        case .sp78: "sp78"
        case .fpe2: "fpe2"
        case .ui8: "ui8 "
        case .ui16: "ui16"
        case .ui32: "ui32"
        case .si8: "si8 "
        case .si16: "si16"
        case .unknown(let tag): tag
        }
    }

    public func decode(_ bytes: [UInt8]) -> Double? {
        switch self {
        case .flt:
            guard bytes.count >= 4 else { return nil }
            let bits = bytes.prefix(4).reversed().reduce(UInt32(0)) { ($0 << 8) | UInt32($1) }
            return Double(Float(bitPattern: bits))
        case .sp78:
            guard bytes.count >= 2 else { return nil }
            return Double(Int16(bitPattern: UInt16(bytes[0]) << 8 | UInt16(bytes[1]))) / 256
        case .fpe2:
            guard bytes.count >= 2 else { return nil }
            return Double(UInt16(bytes[0]) << 8 | UInt16(bytes[1])) / 4
        case .ui8: return bytes.first.map(Double.init)
        case .ui16:
            guard bytes.count >= 2 else { return nil }
            return Double(UInt16(bytes[0]) << 8 | UInt16(bytes[1]))
        case .ui32:
            guard bytes.count >= 4 else { return nil }
            return Double(bytes.prefix(4).reduce(UInt32(0)) { ($0 << 8) | UInt32($1) })
        case .si8: return bytes.first.map { Double(Int8(bitPattern: $0)) }
        case .si16:
            guard bytes.count >= 2 else { return nil }
            return Double(Int16(bitPattern: UInt16(bytes[0]) << 8 | UInt16(bytes[1])))
        case .unknown: return nil
        }
    }

    public func encode(_ value: Double) -> [UInt8]? {
        switch self {
        case .flt: return withUnsafeBytes(of: Float(value).bitPattern.littleEndian) { Array($0) }
        case .ui8: return [UInt8(clamping: Int(value))]
        case .ui16:
            let v = UInt16(clamping: Int(value))
            return [UInt8(v >> 8), UInt8(v & 0xFF)]
        default: return nil
        }
    }
}
```

Naming rules, applied in order (keys are sorted before numbering so "Tp00, Tp04, ..." become "CPU Performance Core 1, 2, ..."):

| Match | Group | Name |
|---|---|---|
| exact `TB0T`/`TB1T`/`TB2T` | battery | Battery 1/2/3 |
| exact `TW0P` | ambient | Wi-Fi Module |
| exact `TCMb` | soc | SoC Package |
| exact `TCDX` | soc | SoC Die |
| exact `TCHP` | power | Charger |
| exact `TAOL` | ambient | Ambient |
| exact `TS0P`, `Ts1P` | ambient | Palm Rest Left / Right |
| prefix `TH0`, `TH1` | storage | SSD n |
| prefix `Tp0` | cpu | CPU Performance Core n |
| prefix `Tp1` | cpu | CPU Efficiency Core n |
| prefix `Te0` (M3/M4) | cpu | CPU Efficiency Core n |
| prefix `Tf` when key length 4 and third char is digit and M3/M4 style: `Tf0`,`Tf4` → cpu "CPU Performance Core n"; `Tf1`,`Tf2` → gpu "GPU Sensor n"; `TfC` → soc "SoC Sensor n" |
| prefix `Tg` | gpu | GPU Cluster X Sensor n (X = 3rd char) |
| prefix `Tm` | memory | Memory n |
| prefix `Ts0` | soc | SoC Sensor n |
| prefix `Ta0` | soc | Neural Engine n |
| prefix `TaL`/`TaR` | ambient | Airflow Left n / Airflow Right n |
| prefix `TV` | power | Power Rail n |
| prefix `TD` | display | Display n |
| prefix `TU`, `TR`, `TP` | other | key string |
| anything else | other | key string |

Overrides: `name` replaces the catalog name, `isFavorite` copied.
